홈페이지 자체 수집

이 홈페이지는 프로젝트를 소개하는 정적 웹페이지입니다. 회원가입, 입력 양식, 결제 기능이 없으며, 방문자가 입력한 개인정보를 수집하는 기능을 운영하지 않습니다. 분석 도구, 광고 스크립트, 추적 픽셀을 사용하지 않습니다. 홈페이지 코드에서 쿠키나 브라우저 저장소를 생성하지 않습니다.

호스팅 서비스의 접속 정보

이 홈페이지는 GitHub Pages에서 제공됩니다. 페이지 요청 시 IP 주소 등의 접속 정보는 호스팅 제공자인 GitHub에서 서비스 제공 및 보안 등의 목적으로 처리할 수 있습니다. 이는 홈페이지 애플리케이션이 직접 정보를 수집하는 것과 구분됩니다. 자세한 사항은 GitHub 개인정보 처리방침을 확인하세요.

연결된 Lotto Studio

Lotto Studio는 별도 프로젝트입니다. 해당 앱은 언어 설정과 최근 생성 번호 기록 등 일부 정보를 브라우저에 저장하는 기능을 제공합니다. 이용 시 앱에 표시되는 안내를 확인하세요. 이 홈페이지는 그 기록을 읽거나 전송하지 않습니다.
